# launch-gate-skill

出海站点的分级上线门禁（P0 阻断、P1 警告、N/A 跳过）。增长和营销清单不是部署阻断。

入口文件是 `SKILL.md`。

把下面整句发给编程助手：

```text
请帮我把这个 Skill（技能）安装到当前项目：https://github.com/oceans777/launch-gate-skill
```

规范仓库：https://github.com/oceans777/launch-gate-skill

统一导航：[oceans777/skills](https://github.com/oceans777/skills)

```sh
python -m unittest discover -s tests -p "test_*.py" -v
```
